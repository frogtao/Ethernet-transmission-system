# Ethernet-transmission-system
系统核心成果如下： 1. 基础功能全面实现：支持以太网指令远程控制LED与数码管, 实现PC与FPGA间双向图片传输与显示, 完成摄像头视频采集并通过以太网实时传输至PC显示 2. 创新扩展功能： 纯FPGA端到端传输：采用双开发板实现不依赖PC的点对点数据传输，验证系统独立性与高可靠性。 双目视频实时拼接：同步接入两路OV5640摄像头，在FPGA内完成视频流处理与左右分屏拼接，输出单一视频流。 可配置图像处理：支持实时灰度化等处理算子，可通过上位机指令动态切换处理模式。 实时运动目标检测：基于帧间差分法，结合二值化、形态学处理，动态标记移动目标并输出带边界框的视频流。
